Resolución del ejercicio N°39 de la unidad 2 de programación 2.
Este programa implementa un sistema modular para un punto de venta (POS) que permite capturar códigos de productos de forma flexible utilizando distintos tipos de lectores ópticos (láser y cámara QR) a través de una interfaz común.

Clases utilizadas
LectorOptico
EscanerLaser
CamaraQR
PuntoVenta
